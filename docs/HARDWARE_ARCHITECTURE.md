# NetLiberation Security Gateway - Hardware Engineering & Architecture Guidelines

## 1. System Hardware Profile & Specifications
The NetLiberation Security Gateway is engineered for ARM/ARM64 Single Board Computers (SBCs) such as Raspberry Pi 4/5, Orange Pi 5, or Rockchip RK3399/RK3588 platforms with at least 1.5GB–2GB RAM.

### Hardware Interface Requirements
- **Ethernet Port**: 1x 10/100/1000 Mbps RJ45 Gigabit Ethernet (`eth0`).
- **Primary Wi-Fi Interface**: Onboard Wi-Fi module (`wlan0`, typically Broadcom/Realtek SDIO or PCIe Wi-Fi chip, supporting AP/STA mode).
- **Secondary Wi-Fi Interface**: External USB Wi-Fi dongle (`wlan1`, e.g., Realtek RTL8812BU / RTL8811CU or Atheros AR9271 with `nl80211` driver support).
- **Power Supply**: 5V / 3A to 5V / 5A USB-C or Micro-USB Power Supply Unit (PSU) with high power stability.

## 2. Thermal Throttling & Power Management

### Thermal Dissipation Strategy
- **Passive & Active Cooling Integration**: SBC SOCs under heavy network routing, hardware-accelerated crypto (AES-NI / ARMv8 Crypto Extensions for WireGuard/OpenVPN), and packet filtering can reach temperatures above 70°C, triggering thermal throttling (reducing CPU frequency from ~1.5–2.4GHz down to 600MHz).
- **Thermal Threshold Monitoring**: The gateway monitors `/sys/class/thermal/thermal_zone0/temp` every 5 seconds.
  - Normal Operating Temp: `< 60°C` (Governor: `schedutil` or `ondemand`)
  - Warning Threshold: `65°C - 75°C` (Governor throttled to `powersave` or frequency capped at 1.2GHz)
  - Critical Threshold: `> 80°C` (Trigger emergency throttling, alert Web UI, drop high-CPU background tasks)

### CPU Governor Tuning
The system backend dynamically manages Linux CPU Governors via `/sys/devices/system/cpu/cpu*/cpufreq/scaling_governor`:
1. `schedutil` (Default): Dynamic frequency scaling based on kernel scheduler load.
2. `performance`: Locks CPU to maximum frequency for low-latency VPN throughput (recommended only with active cooling heatsink/fan).
3. `powersave`: Caps CPU to lowest clock speed to reduce heat generation under elevated thermal conditions.

### Power Delivery Stability
- USB peripheral power draw (especially 5GHz dual-band USB Wi-Fi adapters) can draw up to 500mA–900mA during peak transmit power.
- Undervoltage detection (`dmesg` search for `Under-voltage detected!`) triggers kernel warnings and USB reset events.
- **Hardware Requirement**: Minimum 5V/3A power supply with low cable resistance (<0.1 Ohm) to prevent brownouts under high network load.

## 3. USB Bus Bandwidth Management & Contention Mitigation
- **Shared USB Bus Architecture**: On many SBCs (e.g. older Raspberry Pi or Rockchip models), USB 2.0/3.0 ports share a single USB host controller bus.
- **Bus Contention**: High-throughput Wi-Fi traffic over USB (`wlan1`) combined with USB storage reads/writes can saturate USB controller endpoints and cause packet drops or latency spikes.
- **Mitigation Protocols**:
  1. Isolate USB Wi-Fi dongle to a dedicated USB 3.0 Root Hub port where available.
  2. Enforce USB queue length tuning (`/sys/module/usbcore/parameters/usbfs_memory_mb=32`).
  3. Avoid intensive concurrent USB storage logging by storing fast-changing logs in RAM (`tmpfs` mounted at `/var/log` or memory buffer).

---

## 4. RF Interference Mitigation & Channel Allocation

### 2.4GHz vs. 5GHz Isolation
When operating dual Wi-Fi interfaces concurrently (e.g. Mode B: USB Wi-Fi WAN + Onboard Wi-Fi AP, or Mode C: Onboard Wi-Fi WAN + USB Wi-Fi AP):
- **Frequency Isolation**:
  - Assign Interface 1 (WAN Client) to **5GHz band** (Channels 36–165, e.g., 5200MHz / 5745MHz) to maximize throughput and reduce crowded 2.4GHz spectrum noise.
  - Assign Interface 2 (LAN AP) to **2.4GHz band** (Channels 1, 6, 11 non-overlapping) for maximum range and compatibility with IoT/client devices, or vice-versa.
- **Co-Existence & Antenna Spacing**:
  - Minimum physical separation between onboard antenna and USB Wi-Fi external antenna: **10 to 15 cm**.
  - Use shielded USB extension cables for external Wi-Fi dongles to reduce near-field RF noise generated by SBC high-speed memory buses and CPU clocks.

### Dynamic Antenna Diversity
- Support for external dual-antenna USB Wi-Fi adapters with software diversity switching enabled in `hostapd.conf` (`antenna_rx=3`, `antenna_tx=3`).
